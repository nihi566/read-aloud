カスタムの声を有効にする

各サービスの認証情報を入力して保存すると、その声が声の一覧に追加されます。入力欄を空にして保存すると無効になります。

Amazon Polly
AWS の認証情報を入力すると、Amazon Polly の声を使えます。
Google Wavenet
Google Cloud（GCP）の API key を入力すると、Google Wavenet の声を使えます。
IBM Watson
IBM Cloud の API key とサービスの URL を入力すると、IBM Watson の声を使えます。
Microsoft Azure
Azure Speech のリージョンとキーを入力すると、Microsoft Azure の声を使えます。
OpenAI
OpenAI、または OpenAI 互換の音声合成 API（Speech エンドポイント）を使います。
